# **App Name**: PromptCraft Pro

## Core Features:

- Prompt Catalog: Browse prompts by category, language, and AI model.
- Prompt CRUD (Admin): Add, edit, and delete prompts within the app.
- Favorites & Sharing: Save prompts as favorites and share them via deep links.
- Affiliate Banner Ads: Display affiliate banner ads (Amazon, Shein, AliExpress) with view frequency capped at 8%.
- Multi-Language Support (i18n): Support multiple languages: English, Spanish, Portuguese (Brazil).
- Accessibility Mode: Offer an accessible mode with high contrast theme and dynamic font sizing.
- AI Prompt Generation: Use Gemini 1.5 Flash tool for generating new prompts within the app.

## Style Guidelines:

- Primary color: Saturated purple (#9D4EDD) to evoke creativity and intelligence, aligning with the AI aspect of prompt generation.
- Background color: Dark purple (#241332) to complement the primary, for a sleek look that supports readability and a sense of innovation.
- Accent color: Pink (#F72585) for a contrasting call-to-action element.
- Clear and modern typeface, optimized for readability across various screen sizes and resolutions.
- Consistent and minimalist icons representing categories and actions.
- Clean and intuitive layout, making prompt browsing and editing seamless.
- Subtle animations for user interactions and transitions.
